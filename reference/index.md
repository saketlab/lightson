# Package index

## Download

Fetch nighttime lights rasters from remote sources

- [`ntl_download()`](https://saketkc.github.io/lightson/reference/ntl_download.md)
  : Download VIIRS Black Marble annual nighttime lights
- [`bhuvan_raster()`](https://saketkc.github.io/lightson/reference/bhuvan_raster.md)
  : Download Bhuvan NTL raster tiles for a region
- [`bhuvan_stats()`](https://saketkc.github.io/lightson/reference/bhuvan_stats.md)
  : Get pre-aggregated Bhuvan NTL state statistics

## Analysis

Compute zonal statistics over spatial polygons

- [`extract_panel()`](https://saketkc.github.io/lightson/reference/extract_panel.md)
  : Compute zonal statistics for a panel of rasters

## Visualisation

Plot trends and maps

- [`plot_ntl_trend()`](https://saketkc.github.io/lightson/reference/plot_ntl_trend.md)
  : Plot nighttime lights radiance trends
- [`plot_ntl_map()`](https://saketkc.github.io/lightson/reference/plot_ntl_map.md)
  : Plot a nighttime lights raster map
- [`plot_ntl_panel()`](https://saketkc.github.io/lightson/reference/plot_ntl_panel.md)
  : Plot a multi-year nighttime lights panel
- [`theme_ntl()`](https://saketkc.github.io/lightson/reference/theme_ntl.md)
  : ggplot2 theme for nighttime lights plots

## Boundaries

Indian administrative boundaries

- [`get_india_admin()`](https://saketkc.github.io/lightson/reference/get_india_admin.md)
  : Get Indian administrative boundaries

## Auth & Cache

Authentication and local cache management

- [`earthdata_token()`](https://saketkc.github.io/lightson/reference/earthdata_token.md)
  : Get NASA Earthdata bearer token
- [`cache_clear()`](https://saketkc.github.io/lightson/reference/cache_clear.md)
  : Clear the local lightson cache
