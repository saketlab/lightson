# ggplot2 theme for nighttime lights plots

A clean `theme_minimal()` base tuned for NTL data: tight grid, bold
title, and optional overrides via `...`.

## Usage

``` r
theme_ntl(base_size = 12, ...)
```

## Arguments

- base_size:

  Base font size. Default `12`.

- ...:

  Additional
  [`ggplot2::theme()`](https://ggplot2.tidyverse.org/reference/theme.html)
  arguments.

## Value

A ggplot2 theme object.
