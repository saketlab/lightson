# NA

## Design Context

### Users

Researchers and data scientists working with satellite NTL data. They
open docs mid-coding-session, scan reference pages, copy snippets.
Comfortable with R and spatial concepts.

### Aesthetic Direction

Target feel: tidyverse.org. Clean, uncluttered, functional.

- Body + headings: Albert Sans (0.95rem body, 700 headings)
- Article prose: Literata
- Code: always dark background, both themes
- Colors: deep navy `oklch(14% 0.02 240)` + amber `oklch(72% 0.18 62)`
- Theme: system default, user-toggleable

### Design Principles

1.  Data is the hero
2.  Tight spacing, sharp type, no chrome
3.  Code blocks dark in both themes
4.  No side stripes, no gradient text, no glassmorphism
