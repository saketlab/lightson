# NA

The goals of this package is to create R package to download and process
night time lights data for any part of the world but with a particular
emphasis on India.

One indian source is to download
<https://bhuvan-app1.nrsc.gov.in/bhuvan_ntl/> which is unique but we
should download and support other sources such as:

1.  <https://worldbank.github.io/OpenNightLights/tutorials/mod1_2_introduction_to_nighttime_light_data.html>
2.  <https://www.earthdata.nasa.gov/topics/human-dimensions/nighttime-lights>
3.  <https://eogdata.mines.edu/products/vnl/>
4.  <https://developers.google.com/earth-engine/datasets/catalog/NOAA_VIIRS_DNB_ANNUAL_V21>
